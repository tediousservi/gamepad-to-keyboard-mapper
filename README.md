## What it does

Plenty of PC games accept only keyboard and mouse — older and indie titles, strategy, MOBA and MMO, idle and clicker games, browser games and emulators. If your controller does nothing when you plug it in, PadVolt is the fix. It reads the pad and sends real keyboard and mouse input to whatever window is in focus.

- 🎮 **Any controller** — PlayStation (DualShock 4, DualSense), Xbox (One, Series, 360), generic USB or Bluetooth pads. Recognized instantly, no vendor drivers.
- ⌨️ **Every button mapped** — buttons, triggers and sticks all bind to real keyboard keys
- 🖱️ **Sticks as mouse** — move the cursor with the analog stick, click with shoulder buttons
- 🎯 **Named profiles** — one layout per game, swap in a click
- 📦 **Driver-free & portable** — about 14 MB, no installer, no background service, no admin
- ✅ **Real input** — sends OS-level keyboard/mouse events, so emulators, browser games, and remote desktops all see it
- 🔒 **Open source, MIT** — no ads, no telemetry, no account, no network calls

## FAQ

**Which controllers work?**
DualShock 4, DualSense, Xbox One/Series/360 (wired & wireless), 8BitDo, Steam Controller, generic USB pads, generic Bluetooth pads. If Windows sees your controller in *Game Controllers* panel, PadVolt sees it.

**Does it work in every game?**
Anything that reads keyboard and mouse input, yes. Because PadVolt sends OS-level input events, games can't tell the difference between PadVolt and a real keyboard.

**Do I need admin rights?**
No. Regular-user process, portable, no service, no driver, no registry write.

**Does it work in fullscreen games?**
Yes. Input is sent at the OS level, so it reaches whatever window has focus — including fullscreen and borderless.

**Can I have multiple profiles?**
Yes — one per game. Give each a name, load it before you launch.

**Does it need internet?**
No. Zero telemetry, zero network calls. Runs fully offline.
